## Repository structure

The Ptilon v1 content is organized under `v1/`:

- `docs/` — methodology and operational documentation
- `prompts/` — reusable AI-assisted engineering prompts
- `templates/` — reusable methodology artifacts
- `examples/` — complete worked examples
- `references/` — standards and engineering references
- `assets/` — visual identity and supporting assets

The repository root contains project-level governance, contribution guidance,
automation, licensing, and release history.
