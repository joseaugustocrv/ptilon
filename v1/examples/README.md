# Ptilon Examples

This directory contains examples that demonstrate how Ptilon artifacts
relate across specification, architecture, implementation, verification,
security, quality, traceability, and release activities.

## Available Examples

### User Profile API

A small REST API example demonstrating an authenticated user retrieving and
updating their own profile.

The example includes:

- specification;
- API contract;
- architecture;
- implementation tasks;
- test plan;
- threat model;
- traceability matrix;
- definition of done;
- release checklist.

See `examples/user-profile-api/README.md` for the example overview.
